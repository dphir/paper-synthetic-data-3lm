# Synthetic Data for Integrated Assurance

Notebooks supporting the study Synthetic Data as Analytical Infrastructure for Collaborative Governance Under the Three Lines Model. They cover stratified sampling, AS-IS simulation, synthetic data generation, and TO-BE simulation.

Run the notebooks in numerical order (00 → 03) for matching sample sizes and seeds. Place the required input files in data_source/ beside the notebooks. Source data and generated outputs are excluded from this repository.
